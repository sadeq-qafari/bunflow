# bunflow

Standalone dynamic datastore using the Flow Vue/Quasar interface and a Bun + SQLite backend.

Builds on `main` produce Windows and Linux executables under the repository Actions run artifacts. Push a version tag such as `v1.0.0` to attach both executables to a GitHub Release.

See [standalone/README.md](standalone/README.md) for running, building, API transfers, and compatibility limits.
